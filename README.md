# 特教無障礙語音互動適性試卷生成器 (Special Ed Voice Exam Generator)

專為特殊教育班、資源班、低識字量或聽覺學習學童設計的**無障礙語音互動試卷生成技能（Antigravity Skill）**。
支援國語文、數學、生活管理等全學科，一鍵將試題轉化為自帶**微軟 Edge-TTS 臺灣真人神經語音、純國字大字體、題目與選項獨立語音按鈕、100% 離線完全自包含**的單一 HTML 互動試卷。

---

## 🌟 核心特色與無障礙規格

1. **🎙️ 微軟 Edge-TTS 臺灣真人語音**：
   - 採用 `zh-TW-HsiaoChenNeural` 溫暖親切的臺灣國語女聲。
   - 語速適度放慢 `-5%`，咬字清晰，符合特教學童聽語辨識節奏。
2. **🔊 題目與選項「雙層獨立語音按鈕」**：
   - **題目區塊**：顯眼的 `🔊 聽題目` 藍色大按鈕，可隨時重聽題幹或情境公告。
   - **答案選項**：每一個選項卡片右側設有獨立的 `🔊 聽選項` 彩色按鈕，學生可單純聆聽發音，不必擔心誤觸選取答案。
   - **輔助重聽**：提供「📢 重聽題目」與「🐢 慢速重聽 (0.75x)」功能。
3. **📦 100% 離線完全自包含 (Zero External Dependencies)**：
   - 所有高畫質題目圖卡與合成之 MP3 語音音訊，全數以 Base64 數據格式內嵌於單一 `.html` 檔案中。
   - 即使教室電腦或 iPad **完全沒有網路（離線環境）**，圖文與語音也能 100% 正常播放與互動。
4. **📐 跨學科通用（含數學科口語化轉換）**：
   - 國語文科：生字詞生活圖文配對、生活情境閱讀理解。
   - 數學科：內建算式口語化轉換引擎（例如 `$5 + 3 = ?$` 轉為「五加三等於多少？」、`$35` 轉為「三十五元」、`08:30` 轉為「八點三十分」），支援錢幣換算、時鐘看讀、找零購物等生活數學題型。
5. **📝 自動計分與 IEP 檢核對照表**：
   - 測驗完成後自動結算總分（滿分 100 分），提供逐題對錯紀錄並支援一鍵列印報告。

## 🚀 學校電腦安裝與使用方式 (Installation)

### 方法 1：全域安裝（推薦，學校電腦所有專案皆可使用）

在學校電腦開啟 PowerShell，執行以下單行指令即可安裝：

```powershell
git clone https://github.com/ting03040929-cmyk/special-ed-voice-exam.git $env:USERPROFILE\.gemini\config\skills\special-ed-voice-exam
```

### 方法 2：專案內安裝（只在特定工作區使用）

在任何 Antigravity 專案資料夾根目錄執行：

```powershell
git clone https://github.com/ting03040929-cmyk/special-ed-voice-exam.git .agents/skills/special-ed-voice-exam
```
